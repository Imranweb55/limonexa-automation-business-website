SOLUTIONS PAGE IMAGES — HOW TO ADD
==================================

Save the images directly in THIS folder (src/assets/images/solutions/), using
exactly these file names (.webp, .jpg, .jpeg, .png or .avif). Save, refresh the
browser, and the placeholder is replaced automatically.

Free sources: unsplash.com, pexels.com, pixabay.com
Keep each file under ~300 KB (convert to WebP at squoosh.app).

MAIN IMAGE for each sub-solution (1200 x 900)
  sol-workflow-main     Workflow Automation          (connected nodes, process flow)
  sol-data-main         Data & Analytics             (dashboard, charts)
  sol-assistants-main   AI Assistants                (chat interface, support agent)
  sol-process-main      Business Process Automation  (documents, approvals, office)
  sol-growth-main       Growth & Optimization        (rising graph, team planning)

Other images used on these pages live elsewhere:
  workflow-bg           -> src/assets/images/home/      (Workflow tab background, 1920 x 1080)
  client-1 ... client-6 -> src/assets/images/services/  (trusted client logos)
