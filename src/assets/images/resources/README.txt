RESOURCES PAGE IMAGES — HOW TO ADD
==================================

Save the images directly in THIS folder (src/assets/images/resources/), using
exactly these file names (.webp, .jpg, .jpeg, .png or .avif). Save, refresh the
browser, and the placeholder is replaced automatically.

Free sources: unsplash.com, pexels.com, pixabay.com
Keep each file under ~300 KB (convert to WebP at squoosh.app).

BLOG
  res-blog-featured    1400 x 800   featured article (team, dashboard, workspace)
  res-blog-1 ... 6     1200 x 800   one per article card
                                    (WhatsApp chat, CRM screen, AI chat, invoices,
                                     ROI chart, workflow diagram)

CASE STUDIES
  res-case-1 ... 3     1200 x 800   real estate, clinic, e-commerce store
  (the large featured case study uses  case-study  in src/assets/images/home/)

GUIDES & EBOOKS (book / document covers)
  res-guide-1 ... 4    800 x 1000   portrait covers; design them in Canva
                                    (https://www.canva.com) and export as WebP/JPG
